Tips for Financial Cybersecurity

Essential Security Guidelines

Protecting your personal and financial details online is crucial. Follow these best practices to ensure your digital banking security:

  • Use Strong Passwords: Create unique passwords combining uppercase, lowercase, numbers, and symbols. Never reuse banking passwords across other sites.
  • Enable Multi-Factor Authentication (MFA): Always use MFA or 2FA on online accounts for an added layer of verification.
  • Beware of Phishing: Commonwealth Bank will never ask for your NetBank password or OTP via SMS or email links.
  • Keep Software Updated: Regularly update your operating system and mobile banking applications to patch security vulnerabilities.

Secure Web Hosting Architecture Proposal

TO: Engineering & Infrastructure Management, Commonwealth Bank

FROM: Software Engineering Intern / Analyst

SUBJECT: Secure Hosting & Edge Protection Strategy

1. Executive Summary

Although this financial cybersecurity portal currently serves static information without storing sensitive user data, planning an enterprise-grade secure hosting infrastructure is essential. Future application scope may include interactive user authentication, financial tools, and customer data collection.

2. Hosting Environment Recommendation

We recommend leveraging a Cloud Storage (AWS S3 / Azure Blob) backed by a Content Delivery Network (AWS CloudFront / Cloudflare Edge). This provides high availability, low latency, and removes server-side execution attack vectors.

3. Transport Security & SSL/TLS

All HTTP traffic will automatically redirect to HTTPS using TLS 1.3 encryption. Automated SSL certificate renewal via AWS Certificate Manager (ACM) ensures zero downtime and automated key rotation.

4. Web Application Firewall (WAF) & Edge Security

Deploying AWS WAF at the CloudFront distribution level to filter malicious traffic, restrict rate limits against DDoS attacks, and enforce Content Security Policies (CSP) to mitigate Cross-Site Scripting (XSS).
